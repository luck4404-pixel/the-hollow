# The Hollow — Tales from the Other Side

A single-file horror website built around a flat-design green skull illustration.
Dark, playful, and entirely self-contained.

## Features

- **Hero** — the resident skull ("Specimen #001 — still blinking") with floating bats and a flickering title
- **Live Halloween countdown** — days / hours / minutes / seconds, updates every second
- **Tales from the Crypt Shelf** — three curated horror short stories with fear ratings
- **Horror Talks** — a community wall of dark story confessions with shiver upvotes and a
  "Confess to the dark" submission form (client-side only)
- **Spirits of the Hollow** — resident spirits with hand-drawn flat SVG icons
- **The Fear Meter** — an interactive "Do NOT press this" button that escalates... poorly
- Responsive layout, scroll-reveal animations, reduced-motion support, and a hidden
  message in the browser console

## View it

Open `index.html` in any browser, or visit the live site on GitHub Pages:

**https://luck4404-pixel.github.io/the-hollow/**

## Tech

- Plain HTML + CSS + vanilla JavaScript — no build step, no dependencies
- Self-hosted assets; fonts via Google Fonts CDN
- The skull artwork is included as `skull.png`
